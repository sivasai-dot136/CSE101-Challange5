# CSE101-Challange5
Start
Display the menu using a do-while loop.
Read the user's choice.
If the choice is 1, solve the linear equation \(ax+b=0\).
If the choice is 2, calculate factorial.
Accept only integers from 0 to 12.
Multiply numbers from 1 to n, starting with fact = 1.
If the choice is 3, solve the quadratic equation.
Check that a != 0.
Calculate D = b*b - 4*a*c.
If the choice is 4, display a closing message and exit.
Otherwise, display an invalid-choice message.
Repeat the menu until the user selects 4.
Stop.
